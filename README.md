Squirrels is a simple toy project intended to help me get up-to-date with C++. It's been a long while since I programmed in this language, and I am now curious about how it has evolved and what I can build with it. 

I am using Claude as a tutor to help me quickly explore various concepts and get feedback on the code I write. Some parts of the game is deliberately over-engineered as I'm exploring and learning new things.
